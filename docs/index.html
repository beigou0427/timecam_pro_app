TimeCam Pro（時間相機 Pro）

專為工程巡檢、物流簽收與現場行車紀錄打造的精密時間與 GPS 存證相機：原生全解析度浮水印、SHA-256 數位校驗、4K 影片 20MB／10MB 真位元率壓縮，以及一鍵 A4 PDF 報告匯出。

A precision timestamp camera & field documentation suite built for inspection teams, fleet handoffs, and compact hardware video export.

App Store 下載 / Download on the App Store

核心功能 / Key Capabilities

  • 原生全解析度時間與 GPS 浮水印：直接在全尺寸照片疊加當地即時系統時間、真實衛星定位門牌、經緯度與 SHA-256 檔案摘要，並同步寫入系統相簿拍攝時間與 GPS 位置資訊。
  • 4K 影片位元率壓縮 (20MB / 10MB / 50MB)：支援雙端點起訖時間裁切與硬體 H.264 位元率轉碼，完整保留片段畫面清晰度與目標容量控制。
  • 本機 A4 PDF 驗收報告：支援嵌入現場縮圖、真實紀錄座標、SHA-256 校驗碼與專屬企業抬頭，隨時匯出分享或 JSON 本機備份。
  • 隱私優先保護：照片直接存入系統「照片」圖庫，App 內縮圖與設定全面啟用 iOS FileProtection 加密並排除於 iCloud 備份之外。
